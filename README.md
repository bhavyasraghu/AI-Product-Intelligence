# AI Product Intelligence

An AI-powered product intelligence system for fashion products using CLIP-based image and text embeddings.

## Features

### 1. Smart Product Recommendation

Find visually similar fashion products using image embeddings and similarity-based retrieval.

### 2. Unique Product Catalog

Group visually similar products using clustering to identify duplicate or highly similar products and create a cleaner product catalog.

### 3. Reverse Product Search

Search for products using natural-language descriptions and retrieve visually relevant products using CLIP.

## Dataset

This project uses the **Fashion Product Images (Small)** dataset available on Kaggle.

The dataset is not included in this repository due to its size.

## How to Run

This project was developed and tested using a Kaggle Notebook.

1. Open the notebook.
2. Add the required Fashion Product Images dataset to the Kaggle environment.
3. Enable GPU acceleration for faster model inference.
4. Run the notebook cells in order.
